Boa parte do que faço vive em repositórios privados — aqui vai o resumo do que está por trás dos quadradinhos:

#### 🧠 Com o que eu colaboro

- **VerusBrain.** Plataforma de IA corporativa interna: API FastAPI com RAG sobre a base de conhecimento, cascata multi-provider de LLM, Health Score de clientes e um conjunto de ferramentas internas.
- **Zordon.** Agente de triagem de tarefas apoiado por IA, com escada de risco (observar → simular → agir) e salvaguardas estruturais contra alucinação — separa o que foi dito do que foi suposto antes de deixar algo passar.
- **Mensageria.** Serviço de notificações multi-canal (e-mail, Teams, webhooks) com padrão outbox, retry worker e painel de administração.
- **Sentinel.** Monitor de mudanças em sites com notificação por e-mail (FastAPI + Playwright + PostgreSQL), para acompanhar páginas de terceiros sem precisar checar manualmente.

#### 🛠️ O que eu construo

- **Integrações para cartórios.** API em Python ([`api-hub-cartorios`](https://github.com/Wart3mis/api-hub-cartorios)) para conectar sistemas de cartório a outras plataformas e automatizar fluxos de dados.
- **Dashboards de métricas de produto.** Aplicação desktop em PySide6 que extrai dados de um sistema interno (SQL Server) e calcula métricas de fluxo — lead time (P50/P85/P95), throughput semanal e taxa de retrabalho — com arquitetura em camadas (conexão → extração → métricas → UI) pensada para portar para web no futuro.
- **Aplicações web em .NET.** Sistemas de gestão e vendas com ASP.NET MVC ([`SalesWebMvc`](https://github.com/Wart3mis/SalesWebMvc)), explorando padrões de arquitetura em C#.
- **Fundamentos e lógica.** Projetos como [`xadrez-console`](https://github.com/Wart3mis/xadrez-console) para praticar orientação a objetos e lógica de jogo em C#.
